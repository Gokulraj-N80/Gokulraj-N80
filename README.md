## 🚀 Projects

### 🛡️ ScamShield — AI Phishing & Scam Detector

> **A real-time cybersecurity web app that protects users from phishing texts, emails, and URLs using Google Gemini 2.0 AI and Natural Language Processing.**

🔗 **[Live Demo — Try it now →](https://scam-sheild-w5c9.onrender.com/)**&nbsp;&nbsp;|&nbsp;&nbsp;📂 **[Source Code →](https://github.com/Gokulraj-N80/Scam-Sheild)**

**How it works:**
- 🤖 Paste any text, email or URL — the app sends it to a FastAPI backend powered by **Google Gemini 2.0**, **spaCy** & **NLTK** which scans for urgency patterns, phishing keywords, and suspicious signals
- 🔐 Users log in via **Firebase Authentication** and can view their full scan history on a real-time analytics dashboard
- ⚡ Results are returned in under a second, giving instant threat feedback

**Tech Stack:**
&nbsp;`Python`&nbsp;&nbsp;`FastAPI`&nbsp;&nbsp;`React`&nbsp;&nbsp;`Firebase`&nbsp;&nbsp;`Google Gemini 2.0`&nbsp;&nbsp;`spaCy`&nbsp;&nbsp;`NLTK`&nbsp;&nbsp;`Render`

### 🚌 Bus Ticket Booking System

> **A full-stack bus reservation platform with dedicated Admin and User portals — handling real-world bus management, seat booking, route planning and secure authentication.**

📂 **[Source Code →](https://github.com/Gokulraj-N80/Bus-Booking-System)**

**How it works:**
- 🔑 Users sign in with **Google OAuth 2.0** — Spring Security enforces role-based access so Admins manage buses & routes while Users browse and book tickets
- 🌐 A complete **RESTful API** handles everything: bus registration, route search, seat selection, booking confirmation, and cancellation
- 🗄️ **MySQL** database with a clean relational schema tracks all bookings, routes, and user data

**Tech Stack:**
&nbsp;`Java`&nbsp;&nbsp;`Spring Boot`&nbsp;&nbsp;`MySQL`&nbsp;&nbsp;`Spring Security`&nbsp;&nbsp;`Google OAuth 2.0`
